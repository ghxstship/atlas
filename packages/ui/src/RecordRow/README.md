# RecordRow

RecordRow is one list-view row that answers what now: state, key, title, phase, next date, owner and the next action.

- The next action appears on hover or focus, and is always visible on touch.
- Rows sit inside RecordList, which carries the grid role and the list's name.
- Titles follow each kind's title grammar (Bible tab 24): Task is imperative, Supply and Inspection are noun phrases.
