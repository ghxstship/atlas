# DepartmentGlyph

DepartmentGlyph draws the Lucide icon assigned to each of the 10 department classes.

| Code | Department  | Lucide icon       |
| ---- | ----------- | ----------------- |
| 0000 | Executive   | Briefcase         |
| 1000 | Creative    | Palette           |
| 2000 | Talent      | MicVocal          |
| 3000 | Marketing   | Megaphone         |
| 4000 | Environment | Tent              |
| 5000 | Production  | SlidersHorizontal |
| 6000 | Operations  | ClipboardList     |
| 7000 | Experience  | Sparkles          |
| 8000 | Hospitality | ConciergeBell     |
| 9000 | Technology  | Cpu               |

The map is exported as `XOS.glyphs.departments`. Always shown beside the department name, never alone.
