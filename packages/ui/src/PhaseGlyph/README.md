# PhaseGlyph

PhaseGlyph draws the Lucide icon assigned to each of the nine gated phases.

| Gate | Code | Phase   | Lucide icon    |
| ---- | ---- | ------- | -------------- |
| 1    | SCP  | Scope   | Crosshair      |
| 2    | ENG  | Engage  | Handshake      |
| 3    | ADV  | Advance | ClipboardCheck |
| 4    | PRC  | Procure | ShoppingCart   |
| 5    | BLD  | Build   | Hammer         |
| 6    | INS  | Install | Wrench         |
| 7    | OPR  | Operate | Play           |
| 8    | AMP  | Amplify | Share2         |
| 9    | CLS  | Close   | Archive        |

Exported as `XOS.glyphs.phases`.
