# ProofStatStrip

ProofStatStrip shows a row of verifiable figures, each linked to the file that proves it.

Figures use tabular numerals and format with the page locale. Every figure on a public page comes from the repository or the canon and carries a `source`, so a reader or an answer engine can check it. Use three to five figures; they sit in one row from bp-lg, two columns from bp-sm and one column below.

The consumer provides the value, a short label and the source link. Never use a figure that has no source.
