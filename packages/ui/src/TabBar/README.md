# TabBar

TabBar is the five-destination bottom bar for phones: Compass always, Gateway and Atlas below the md breakpoint.

- Destinations and order come from the sitemaps (Section 4.5): Compass Today, Schedule, Scan, Inbox, More, with Scan raised in the center; Gateway Home, Explore, Work, Money, Messages; Atlas Home, Inbox, Search, My Work, Menu.
- Supervisors get a sixth Compass tab, Crew, only when their role allows it.
- Targets meet touch-min (48 pt).
