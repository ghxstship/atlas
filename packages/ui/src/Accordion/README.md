# Accordion

Accordion progressively discloses sections; use it for the More fields pattern past seven visible fields.

Inside a form, pass `keepMounted` so collapsed fields stay in the DOM, hidden, keep their values and submit with the form. Title the section with the "More fields" label and put every field past the seventh in it.

`MoreFields` is that section ready-made: an Accordion titled with the catalog's "More fields", kept mounted.
