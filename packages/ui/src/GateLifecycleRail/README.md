# GateLifecycleRail

GateLifecycleRail lays out the nine gates in their three acts, each with one criterion from the canon.

The three acts sit side by side from bp-lg and stack below it; gates run top to bottom inside each act, so reading order always matches gate order. Each gate reads "Gate 3 · Advance" beside its phase glyph: the number never stands alone. All text is visible without interaction.

The consumer provides the acts and gates. `evidence` quotes one criterion as the canon writes it (`xpms.dim_gate_criterion`); do not paraphrase a criterion.
