# URIDChip

URIDChip pairs a plain name with its URID in JetBrains Mono, at discipline or category grain.

- Canon disciplines and categories hold .01 to .49; adopter extensions hold .50 to .99 and are scoped to their org. The preview's second chip, Northwind Line Array Kit (5000.01.50), is a Northwind Live extension under canon discipline Audio (5000.01).
