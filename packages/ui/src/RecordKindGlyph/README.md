# RecordKindGlyph

RecordKindGlyph draws the Lucide icon assigned to each of the 26 record kinds, grouped by class.

| Class      | Kind         | Lucide icon   |
| ---------- | ------------ | ------------- |
| Work       | Build        | Construction  |
| Work       | Rehearsal    | Repeat        |
| Work       | Shift        | CalendarClock |
| Work       | Strike       | PackageX      |
| Work       | Task         | SquareCheck   |
| Work       | Training     | GraduationCap |
| Artifact   | Document     | FileText      |
| Artifact   | Supply       | Package       |
| Commitment | Booking      | CalendarCheck |
| Commitment | Contract     | FileSignature |
| Commitment | Payment      | Banknote      |
| Commitment | Recruitment  | UserPlus      |
| Control    | Approval     | Stamp         |
| Control    | Compliance   | ShieldCheck   |
| Control    | Deadline     | AlarmClock    |
| Control    | Decision     | Split         |
| Control    | Inspection   | ScanSearch    |
| Control    | Permit       | BadgeCheck    |
| Time       | Distribution | Send          |
| Time       | Event        | Ticket        |
| Time       | Goal         | Target        |
| Time       | Meeting      | Users         |
| Time       | Milestone    | Milestone     |
| Time       | Report       | ChartColumn   |
| Time       | Risk         | TriangleAlert |
| Time       | Timeline     | ChartGantt    |

Exported as `XOS.glyphs.recordKinds`. The Build kind uses Construction so it stays distinct from the Build phase (Hammer).
