## Fulfillments

A fulfillment is one hospitality need met: a room, a meal, a transfer. Assign it, then confirm it when the supplier confirms.

## Banquet event orders

A banquet event order (BEO) tells the caterer exactly what to serve, when and where. Generate it from the catering fulfillments of an event and send it for confirmation.

## Accommodation blocks

An accommodation block holds rooms at a hotel for a date range. Assign people to rooms from the block and see how many remain.

## Import itineraries with Aurora

On a Travel fulfillment, **Import itineraries with Aurora** reads up to 25 booking confirmations, as files or as verified messages in the project inbox, into one preview. Each file is one Aurora request from this month's allowance, and the panel says how many you use. Every row is one passenger on one segment, with the excerpt it was read from. You always choose the traveler: a suggested name is only a hint. Zones are read from each place, so check them; a date or time the confirmation does not print is left empty. **Add segments** adds the rows you keep in one step, and a segment the traveler already has is refused.
