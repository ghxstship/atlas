The scope tree breaks a project into the parts you plan and report by: the engagement at the root, then shows, sites, days and workstreams below it.

## Work with the tree

- Use the arrow keys to move: **Right** expands a branch or enters it, **Left** collapses it or returns to the parent.
- Press **Enter** to select a node and see its details.
- Switch to the table view to see every node with its code, kind and venue.

## Add and change nodes

Choose **Add** on the node you want to extend, pick the kind of node and give it a name. A node's code is unique within the project. People with read access see the tree but cannot change it; the page says so at the top.
