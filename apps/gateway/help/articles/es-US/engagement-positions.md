Puestos es para el personal. Agrupa tus turnos por el puesto que cubre cada uno, con el inicio, el proyecto, el fin y el estado de cada turno.

Los puestos se asignan cuando terminas la capacitación. Para aceptar un turno que te espera, abre [Turnos](help:engagement-shifts).

Esta pestaña se abre cuando la contratación pasa a Activa, después de la incorporación, y se cierra cuando se completa o se cancela.
