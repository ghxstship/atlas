Los tokens personales de API permiten que tus propios scripts llamen a la API de XOS en tu nombre, cada uno en una organización y limitado a las áreas que elegiste. Esta sección aparece cuando una organización a la que perteneces los permite.

- Cada token muestra su organización, el inicio del token, sus áreas, cuándo vence y cuándo se usó por última vez, con la etiqueta **Activo**, **Vencido** o **Revocado**.
- **Revocar** detiene un token de inmediato. Hazlo en cuanto dejes de usar uno o creas que otra persona lo tiene.
- **Crear un token en Gateway** abre Gateway. Un token se muestra solo una vez y pertenece a la computadora que ejecuta tu script, así que créalo allí; crearlo también pide tu segundo factor.

La lista se muestra sin conexión; revocar necesita conexión.
