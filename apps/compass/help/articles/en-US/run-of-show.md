Run of Show lets you follow today's running order cue by cue, with the next cue counting down and how many cues are called. The stage manager calls the cues; you follow along. A cue whose time is still to be confirmed shows **TBC** instead of a countdown. A cue more than 12 hours away shows the day and time it is planned for, such as **Planned for Nov 14 at 8:00 PM**, instead of a countdown.

When the project has more than one running order, such as a main stage and a side stage or one for each show day, the **Running order** button names the one on screen. Tap it to pick another. Each running order reads on its own, and the screen stays on the one you picked.

**Show Mode** turns the screen dark and keeps it awake.

When there is no running order today, the screen says so. The organization shares it in Gateway too, under the engagement's Run of Show tab.
