Run of Show lets you follow today's running order cue by cue, with the next cue counting down and how many cues are called. The stage manager calls the cues; you follow along. A cue whose time is still to be confirmed shows **TBC** instead of a countdown.

**Show Mode** turns the screen dark and keeps it awake.

When there is no running order today, the screen says so. The organization shares it in Gateway too, under the engagement's Run of Show tab.
