Personal API tokens let your own scripts call the XOS API as you, each in one organization and limited to the areas you chose. This section appears when an organization you belong to allows them.

- Each token shows its organization, the start of the token, its areas, when it expires and when it was last used, tagged **Active**, **Expired** or **Revoked**.
- **Revoke** stops a token at once. Do it as soon as you stop using one or think someone else has it.
- **Create a Token in Gateway** opens Gateway. A token is shown only once and belongs on the computer that runs your script, so create it there; creating one also asks for your second factor.

The list shows offline; revoking needs a connection.
