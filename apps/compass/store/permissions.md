# Compass: permissions review (iOS and Android) and Android target SDK

Every permission Compass asks for or declares, why, and what A68 (RRR-113) removed. Read from `app.json`, the Expo config plugins (`expo prebuild` output) and the manifest of every autolinked library on main 7ccd1fd9. `test/store-release.test.ts` holds the decisions in place.

## iOS

| Permission                              | Asked                                                             | Used by                                                                         | Decision                                                                                                                |
| --------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Camera                                  | When the person opens Scan or adds a photo                        | Badge, asset and barcode scanning; field photos                                 | Keep                                                                                                                    |
| Microphone                              | When the person first holds the voice note button                 | Voice notes on incident reports                                                 | Keep                                                                                                                    |
| Location when in use                    | On shift, and when reporting an incident                          | On-site clock in; incident location                                             | Keep                                                                                                                    |
| Location always                         | Never                                                             | Nothing                                                                         | Never requested; the purpose string exists only because `expo-location` links the API (`store/ios/privacy-manifest.md`) |
| Motion                                  | Never                                                             | Nothing                                                                         | Same                                                                                                                    |
| Face ID                                 | When the person turns on Biometric Unlock, or deletes the account | App lock and the deletion check                                                 | Keep                                                                                                                    |
| Notifications                           | From Inbox, when the person chooses to get them                   | Approvals and announcements (journey 57)                                        | Keep                                                                                                                    |
| Photo library                           | Never                                                             | Nothing                                                                         | Not declared                                                                                                            |
| Background modes                        | None                                                              |                                                                                 | Removed `audio` (`expo-audio` added it by default; nothing plays in the background)                                     |

| `USE_FINGERPRINT`                                                                        | `expo-local-authentication`             | Normal                   | Keep: biometrics on Android 9 and earlier (minimum SDK 24)                                                                                                                                                               |

## Android target SDK

- Compass targets **API 36 (Android 16)** and compiles against 36, with a minimum of 24. The values come from React Native 0.86's version catalog (`react-native/gradle/libs.versions.toml`), which Expo SDK 57 uses through `useExpoVersionCatalog()`; `app.json` sets none of its own.
- Google Play requires new apps and updates to target API 36 since 31 August 2026 (extensions to 1 November 2026 on request), per the Android developers page "Meet Google Play's target API level requirement", read 2026-10-20. Compass meets it with no extension.
- `test/store-release.test.ts` fails if the target ever drops below 36.

## Firebase for Android push

`expo-notifications` needs Firebase Cloud Messaging for an Expo push token on Android. Without a `google-services.json` Compass still runs; it only skips Android push registration. The owner creates a Firebase project with an Android app for `pro.ghxstship.compass`, uploads the FCM V1 service account key to EAS (`npx eas credentials`, Android, Push Notifications), and stores `google-services.json` as an EAS file variable named `GOOGLE_SERVICES_JSON`; `app.config.ts` passes it to the build. The runbook has the commands.
