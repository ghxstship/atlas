# Compass: Google Play Data safety and App content answers

The answers for Play Console, App content, for Compass 4.0.0 (`pro.ghxstship.compass`). Prepared by A68 (RRR-113) on main 7ccd1fd9 from the same code reading as the App Store answers (`store/ios/app-privacy.md`, which names the source of each data type). The owner enters them in Play Console; nothing uploads them automatically.

Play's terms: **collected** means sent off the device; **shared** means sent to a third party. Processors acting for GHXSTSHIP (Supabase, Expo push, Firebase Cloud Messaging, Anthropic when Aurora is on) are service providers, which Play does not count as sharing. Data handled only on the device (the encrypted offline database, biometrics, the geofence check before a punch) is not collected.

### Security practices shown on the listing

- Data is encrypted in transit: Yes.
- You can request that data be deleted: Yes, in the app (More, Settings, Delete Account) and at the delete account URL.
- Independent security review (MASA): No, not done.
- Committed to the Families Policy: not applicable; Compass is not for children.

## Check against the first build

The permission list above comes from `app.json`, the Expo config plugins and every autolinked library manifest (`store/permissions.md`). Libraries pulled from Maven (Firebase Cloud Messaging, CameraX, ML Kit, AndroidX Biometric) merge their own entries at build time, so check the first EAS build's merged manifest before filling the form:

```sh
cd apps/compass
npx eas build:list --platform android --limit 1        # copy the artifact URL of the .aab
bundletool dump manifest --bundle compass.aab | grep -E 'uses-permission|foregroundServiceType'
```

Play Console shows the same list under Test and release, App bundle explorer, Permissions. Anything not in `store/permissions.md` goes to engineering before the form is submitted.

## Open questions for the owner

1. **Deletion without deleting the account.** Answered No. If counsel wants the privacy policy's request process counted, answer Yes and give the policy's rights section as the link.
2. **Health.** As in the App Store answers: if organizations use incident reports for injury and first-aid records, consider declaring Health info. Counsel decides.
3. **Sentry.** When Sentry is added to Compass, add Crash logs and Diagnostics (App functionality, Analytics if traces are sampled) in the same release.
