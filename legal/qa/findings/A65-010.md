# A65-010: Automations are a plan feature with nothing behind it

## Finding

Section 7.3 lists `automations` and `automation_runs` in the workflow engine, Section 4.5.6 item 20 is Settings,
Automations, and Section 16 puts automations in Pro and above. `automations` is a plan feature in `plans.yaml` and
`org.automations.write` is a capability (0203), but there are no tables, no operations, no runner and no settings
content: the page is an empty state.

## Why it matters

The Pro plan advertises a capability that does not exist.

## Suggested fix

Model triggers on `app.domain_events` (the webhook catalog already lists 41 event types), conditions over the
event payload and actions through public API operations run as the automation's owner (so RLS and capabilities
still decide), with an `automation_runs` ledger and retries on the job queue. Gate it on the `automations`
feature.
