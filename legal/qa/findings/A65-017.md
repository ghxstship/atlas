# A65-017: Security checks written but not run

## Finding

Section 9 supply chain asks for a CycloneDX SBOM per release; `legal/open-source-licenses.md` says each release
ships one and the page is generated from it. No step generates an SBOM. Section 9 testing asks for a ZAP baseline
against staging; nothing runs ZAP. Section 10.3 asks for the license compliance check in CI; `licenses:check`
exists but `.github/workflows/ci.yml` does not run it. Gate 11 records the Semgrep, audit and advisors scripts as
written but not in `ci.yml`.

## Why it matters

The Open Source Licenses page promises an artifact that is never produced, and known security checks do not
block a merge.

## Suggested fix

Add an SBOM step (`@cyclonedx/cyclonedx-npm` or `syft`) to the release workflow attached to each release; a ZAP
baseline job against staging once it exists; `licenses:check`, Semgrep, audit and advisors jobs in `ci.yml`.
