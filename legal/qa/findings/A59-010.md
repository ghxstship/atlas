# A59-010: Wrong empty-state copy on Safety pages

## Finding

Opening Incidents with `?create=1` and no project (the create-link convention of
`apps/atlas/ia/routes.config.ts`, where a page's empty-state action opens its create flow) shows a card reading "Choose a project first. Credentials,
zones and the access grid belong to one project." with an "Open NWG" button, above the incident
list. No create form opens. The copy talks about credentials on the Incidents page. The notice comes
from `chooseProjectNotice` in `apps/atlas/components/operations/chrome.tsx` (line 118), which always
uses `credentials.common.chooseProject`, so every operations section that calls it inherits the
Credentials sentence. The button opens the first project alphabetically (NWG), not the one the
person works on.

## Steps

1. Sign in as producer@example.com.
2. Open /demo-productions/safety/incidents?create=1.
3. Read the dashed card; no Report incident form appears.

## Screenshots

- `legal/qa/visual-review/evidence/A59-010-1.jpg`
- Full resolution: `legal/qa/visual-review/shots/states/atlas-create-forms/01-incidents_create.*`

## Suggested fix

Pass the section's own sentence to `chooseProjectNotice` ("Choose a project to report an
incident"), and on `?create=1` open the form with a project picker instead of a notice.
