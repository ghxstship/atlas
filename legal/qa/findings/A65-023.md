# A65-023: No PWA

## Finding

Section 4.10: "Gateway and Atlas are installable as progressive web apps, with web push and an offline read
cache." Neither app has a web manifest, a service worker or web push.

## Why it matters

Gateway users on phones (its primary audience, Section 11.12) cannot install it or receive web push.

## Suggested fix

Add `app/manifest.ts` to both apps, a service worker with an offline read cache for recently viewed pages (within
the route budgets of ADR 0027), and web push subscriptions in `push_subscriptions` with VAPID keys from the owner.
