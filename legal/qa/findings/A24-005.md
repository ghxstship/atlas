# A24-005: Maestro not run

## Finding

Gate 7 requires the Compass field journeys in Maestro on iOS and Android, including airplane-mode
runs and queue drain. The 11 flows exist in `apps/compass/.maestro`, and the Maestro CLI is present
in `~/.maestro`, but it needs a Java runtime (not installed; `java -version` reports none) and the
iOS build needs CocoaPods (not installed). A24 does not install system software. Journeys 5, 10, 15,
16, 17, 38, 52 to 54, 58 and 65 depend on these runs for their Compass steps.

## Decision needed

Either approve the `maestro-ios` (macOS runner, Xcode and CocoaPods preinstalled) and
`maestro-android` (Temurin 21 and an emulator) jobs in `packages/testing/ci/proposed-jobs.yml`,
which cost GitHub macOS minutes, or approve installing a JDK and CocoaPods on the build machine.
