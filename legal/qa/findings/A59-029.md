# A59-029: Same job, different control

## Finding

- One row, four button styles: the invoice peek shows "Download PDF" (outlined), "PDF (A4)"
  (ghost), "Dispute" (red outline) and "Record payment" (an underlined link).
- Filters apply three ways: live filtering (Projects), a Search button (Records, Run of Show) and
  an Apply button (Units, Credentials, Incidents, Dispatch Board).
- View switchers list the same views in different orders on neighboring tabs: Gateway Work >
  Engagements is "List, Table, Board", Work > Applications is "List, Board, Table".
- Compass uses Title Case for actions ("Email Me a Link", "Use Password", "Clock In", "Delete My
  Account") while Atlas and Gateway use sentence case ("Sign in with password", "Create project").
- Clicking a table row in Atlas only highlights it; the peek opens on Enter or double-click, with
  no visible cue that rows open.
- Projects > Templates has three filled primary buttons on one page (Create template, Create
  project, Save defaults) and reads "Inspection record · phase No phase" for unphased lines.

## Steps

1. Open an invoice in Atlas Finance > Invoices; compare filter bars on Projects, Units and Records;
   compare Gateway Work tabs; open Compass sign-in.

## Suggested fix

One action-row pattern (primary, secondary, overflow), one filter behavior, a fixed view order,
one casing rule for all three shells, and a hover affordance on openable rows.
