# A59-018: Four to ten Save buttons on one settings page

## Finding

Each registered setting renders its own control, "Platform default. Saving sets it for the
organization." and its own Save button. General has four Saves, Security five, Workspaces seven,
Localization four, Communication five. Some sections add a primary button of their own ("Save
profile", "Save brand", "Save modules", "Create invite"). A person who edits three fields must
press three Saves, and nothing marks which fields are unsaved. Section 11.6 defines the Settings
template as a centered form column with a sticky save bar when dirty, and Section 11.10 allows one
primary action per screen. The /settings index page also repeats the section list in the content
column next to the same list in the left rail.

## Steps

1. Sign in as owner@example.com.
2. Open /demo-productions/settings/general and count the Save buttons.

## Suggested fix

Collect dirty fields per section and save them with one sticky bar (Save, Discard), keeping the
per-field "Platform default" line as help text.
