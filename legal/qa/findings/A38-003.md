# A38-003: Shared profiles and org profiles

## Finding

Journey 61: an application shares only the full name and email (and the company name when acting as
an account); there is no way to share the whole profile, or a chosen set of sections, with the org
applied to. Atlas has no view of what a candidate shared: the org can read
`app.profile_share_fields` through its row level security, but no Pipeline or application page shows
it.

Journey 62: the company page at `/c/{handle}` shows about, the verified badge, capabilities, regions,
team and open opportunities, but not case studies (`app.organization_case_studies` exists with client
consent and is never rendered), and Explore lists opportunities only, so an org's Public profile
never "appears in Explore". The verified domain line renders only from profile details, not from the
org's verified `app.org_domains` row, so the demo org shows the badge without the domain.

## What the journeys cover today

profile-journeys.spec.ts: Network visibility with rates Private (stranger 404, collaborator sees
Network fields without rates), the name and email shared through an application and readable only
by that org; the org's Public profile saved in Atlas, shown in Gateway with the badge and open
opportunities, noindex by default.

## Proposal

Gateway: section choices in the apply form's sharing block; a case studies section on the company
page; an Organizations tab in Explore for Public org profiles. Atlas: a "Shared with you" panel on
the application in Pipeline.

## Fix (A44, RRR-88)

- `app.share_profile_sections`: chosen sections of the person's own profile, read from the profile, join the share an application carries; Atlas shows them on the application as Shared with you.
- `app.explore_organizations`: Public organization profiles with the verified badge, verified domain and open Public opportunities, in Gateway Explore, Organizations; indexing stays off by default.
- The company page renders published case studies; seed 1130 gives the demo org a verified domain row and two case studies.
