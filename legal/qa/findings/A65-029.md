# A65-029: Nightly Parquet delivery is a flag only

## Finding

Section 4.6.4: "Warehouse delivery (Enterprise): nightly Parquet files to the customer's own S3, Google Cloud
Storage or Azure Blob bucket, with a published schema." Section 7.3 lists `warehouse_deliveries`. Only the feature
flag row `reports.warehouse_delivery` exists (0540).

## Why it matters

An Enterprise feature that cannot be delivered.

## Suggested fix

A `warehouse_deliveries` table with bucket credentials in Vault, a nightly worker writing Parquet per table read
with the org's own access, and a published schema page in the docs site.
