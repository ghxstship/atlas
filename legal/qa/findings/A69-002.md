# A69-002: private.request_ip() trusted the first forwarded entry

## Finding

`private.request_ip()` (0501) returned the first entry of `X-Forwarded-For`. Proxies append the address they saw to
whatever header the client sent, so the first entry is text the client writes. On the local stack (the same Kong
gateway the self-hosted stack runs), a POST with `X-Forwarded-For: 203.0.113.77` reached PostgREST as
`203.0.113.77, 192.168.65.1`, and the failure was counted against 203.0.113.77.

## Impact

- The per-address failure limits of `verify_certification` (10 per 15 minutes), `calendar_feed_events` (20) and
  `record_cookie_consent` (30) reset whenever the caller changed the header.
- The audit ledger (`private.write_audit_event`), the file access log and consent records stored whatever address the
  caller claimed, which weakens them as evidence.

Verification codes and calendar tokens are 96 and 256 random bits, so the limits were defense in depth rather than the
only control.

## Fix

The address is the entry the trusted gateway appended, counted from the right:

- `xos.trusted_proxy_hops` (a database setting, default 0) counts further trusted proxies between that gateway and
  PostgREST. 0 takes the last entry, which is right for the local and self-hosted Kong stack.
- A chain shorter than the trusted hops skipped a proxy, so the address is unknown (NULL).
- `X-Real-IP`, which the gateway sets itself, is used only when no chain was sent.

The hosted Supabase edge may add another hop. `infra/runbooks/hosted-security-settings.md` says how to read the chain
on staging and set the hop count; it was not checked here because this review sent no traffic to hosted systems.

## Test

`1296_request_ip_trusted_hop.test.sql`: a spoofed first entry is ignored, one trusted hop is honored and a short chain
is unknown, malformed values are NULL, ten misses with ten different spoofed entries count against the one real address,
and a catalog assertion keeps `private.request_ip` the only function that reads the forwarding headers.
