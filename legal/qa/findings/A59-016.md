# A59-016: Peek shows title, project and owner only

## Finding

The shell's global peek for NWS-12 (Production Meeting) shows the kind, the title, a state chip,
Project and Owner, then the sentence "Open the full page for the record's content, comments and
activity." The full page (/r/NWS-12) has the move-to buttons, the edit form, the property column
(Kind, Class, Phase, Scope node, Starts, Ends, Due, Time zone) and activity. Section 11.2 item 4
says every record opens in a side peek and a full page with the same layout: title, kind and state,
a property column, activity and comments, related records. Module pages (Invoices, Incidents) do
show a full peek, so the gap is the shell's generic one, used from Home, Activity, notifications
and search.

## Steps

1. Sign in as producer@example.com.
2. Open /demo-productions/home?peek=NWS-12.
