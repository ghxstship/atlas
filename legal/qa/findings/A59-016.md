# A59-016: Peek shows title, project and owner only

## Finding

The shell's global peek for NWS-12 (Production Meeting) shows the kind, the title, a state chip,
Project and Owner, then the sentence "Open the full page for the record's content, comments and
activity." The full page (/r/NWS-12) has the move-to buttons, the edit form, the property column
(Kind, Class, Phase, Scope node, Starts, Ends, Due, Time zone) and activity. Section 11.2 item 4
says every record opens in a side peek and a full page with the same layout: title, kind and state,
a property column, activity and comments, related records. Module pages (Invoices, Incidents) do
show a full peek, so the gap is the shell's generic one, used from Home, Activity, notifications
and search.

## Steps

1. Sign in as producer@example.com.
2. Open /demo-productions/home?peek=NWS-12.

- `legal/qa/visual-review/evidence/A59-016-1.jpg`

## Suggested fix

Render the record page's body (properties, activity, comments) inside the generic peek, as the
module peeks already do.

## Resolution (A61, RRR-106)

The global peek shows the record's key properties (project, owner, phase, starts, ends, due, time zone, blocker), its latest state changes with who, when and why, and an Open full page link.

After: `legal/qa/visual-review/fixes/A61/after/A59-016-1-peek.jpg`; before: `legal/qa/visual-review/fixes/A61/before/`.

## Follow-up (A114, RRR-159)

The global peek now shows the sections of the record's full page below its properties and recent activity: the
comment thread with its files, and the related records (parent, sub-records, dependencies, linked custom object
records), read by the same loaders as the full page and the work peeks (ADR 0074). Regression test: the parity journey
in `apps/atlas/e2e/shell-peek.spec.ts`.
