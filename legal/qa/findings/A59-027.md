# A59-027: Feed post control row

## Finding

Each post shows "Thumbs up 1, Heart 0, Check 0, Eyes 0, Laugh 0, Celebrate 0" as six outlined
text buttons, then "Acknowledge, Unpin, Turn comments off, Turn reactions off, Hide, Comments" as
six more, wrapping onto two lines on a 1000 px column. Section 11.10 item 8 asks for a small
curated set of glyphs from the XOS icon set for reactions, and the cognitive load budget allows at
most five visible toolbar actions; moderation actions belong in an overflow menu.

## Steps

1. Sign in as owner@example.com, open /demo-productions/knowledge/feed.

## Screenshots

- `legal/qa/visual-review/evidence/A59-027-1.jpg`

## Suggested fix

Glyph reactions with counts shown only when non-zero, Acknowledge and Comments as the visible
actions, everything else in a "More" menu.
