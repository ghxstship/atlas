# A69-004: isPublicAddress missed hex-mapped IPv4 and special blocks

## Finding

`isPublicAddress` decides whether a webhook endpoint (`webhook-dispatch`) or a ticketing API base URL may be called. For
IPv6 it refused `::1`, `::`, `fc`/`fd` and `fe8` to `feb` prefixes and the dotted mapped form `::ffff:a.b.c.d`, and
called every other string with a colon public. So it accepted:

- IPv4-mapped addresses in hex, the form DNS answers and `URL` normalization use: `::ffff:7f00:1` (127.0.0.1) and
  `::ffff:a9fe:a9fe` (169.254.169.254, cloud metadata);
- IPv4-compatible `::7f00:1`, NAT64 `64:ff9b::7f00:1`, site-local `fec0::/10` and multicast `ff00::/8`.

For IPv4 it missed 192.0.0.0/24, the documentation blocks, 192.88.99.0/24, 198.18.0.0/15, multicast 224.0.0.0/4 and
reserved 240.0.0.0/4.

The endpoint URL column refuses IPv6 literals, so the way in is a host name: an integration manager registers a webhook
on a domain whose AAAA record is `::ffff:7f00:1`. The worker resolves it, the guard calls it public, and the POST goes
to the Edge runtime's own loopback.

## Impact

Blind SSRF from the Edge Functions: a signed JSON POST to an internal address, with the response status and connection
errors recorded on the delivery the manager can read (enough to map ports). The ticketing feed, once its worker is
deployed, would also read the response body.

## Fix

`isPublicAddress` parses IPv6 fully (compression, dotted tails, no zone ids), judges IPv4 written as IPv6 (mapped,
compatible, NAT64) by the IPv4 rules, allows IPv6 only in global unicast 2000::/3 outside its special blocks (2001::/23
with Teredo, 2001:db8::/32, 2002::/16, 3fff::/20), and refuses every IPv4 special-purpose block. The Edge bundle is
regenerated.

## Residual risk

The guard resolves the host, then `fetch` resolves it again, so a DNS server that changes its answer in between
(rebinding) can still reach an internal address. Closing that needs the request to connect to the address that was
checked, which the Deno `fetch` used by the Edge Functions does not offer. Recorded in the threat model.

## Test

`services.test.ts` refuses 32 addresses (hex-mapped loopback and metadata, NAT64, compatible, multicast, site-local,
documentation, 6to4, Teredo, malformed, zone ids and every IPv4 special block) and admits public IPv4, public IPv6 and
NAT64 of a public address. The old guard fails it on the first address.
