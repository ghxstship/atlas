# A24-008: Journeys not run in Firefox and WebKit

## Finding

Section 18, gate 6 runs the critical journeys in Chromium, Firefox and WebKit plus mobile viewports.
The Atlas and Gateway configs define `chromium` and a Pixel 7 `mobile` project; docs runs Chromium
and phone width. The Storybook visual job already runs three engines for components.

## Proposal

Add `firefox` and `webkit` projects to the Atlas and Gateway configs behind `E2E_ENGINES`, and run
them in the proposed `e2e` CI job as a matrix dimension (about 3 times the minutes). Locally only
Chromium build 1243 is installed; the pinned Firefox and WebKit builds for Playwright 1.64 are not,
so the engines were not run here.
