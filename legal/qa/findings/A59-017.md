# A59-017: "Missing: G1.GONOGO"

## Finding

Section 11.10 item 2: canon codes always appear next to a plain name, never alone; gates read
"Gate 3 · Advance", never "ADV". The review found:

- Pass gate dialog refusal: "Gate 1 cannot pass until every blocking criterion has evidence.
  Missing: G1.GONOGO." (no criterion name).
- Gate criteria list and "Attest evidence for G1.BUDGET_ENVELOPE" dialog title lead with the code.
- Reports > Gate Readiness: the Phase column shows "SCP" and "ENG" only, and "Unmet blocking
  criteria" lists codes only. Home > Gate readiness "Missing evidence" is codes only.
- Work > Recurring: the rule shows as `FREQ=WEEKLY;BYDAY=MO`.
- Activity > Audit Log: action `goods_receipts.update`, subject `goods_receipts`.
- Canon > Metrics: domain `restrooms_ada`, `capacity`.
- Aurora's refusal card carries a raw "REFUSE" chip before "Aurora cannot do this".

## Suggested fix

Render gates as "Gate 1 · Scope", criteria as their plain sentence with the code in a chip, the
recurrence as "Weekly on Monday", and audit actions as "Updated a goods receipt".

## Resolution (A61, RRR-106)

Gate refusals, criteria, the attest dialog, Gate readiness (report and Home) name criteria by their sentence with the code after it; phases read as names; recurrence reads "Weekly on Mon"; the audit log reads "Updated a goods receipt" with the code beside it; canon metric domains have names; refusal notices show the outcome in words.
