## Compass on the iOS simulator (A39)

A39 walked the Compass device journeys on an iPhone 17 Pro simulator (iOS 26.5) with a development build,
against its own freshly seeded stack (block 579, migrations to 1092). The simulator has no camera, so codes
were typed into the manual entry, and the host network could not be cut, so "offline" meant stopping the
stack's API gateway: Compass's queue and retry handling then carried the writes until it returned. All
15 Maestro flows in `apps/compass/.maestro` pass on the simulator except `field-clock-offline`, which needs
airplane mode (Android only in Maestro). Beyond the journey rows above:

- Kiosk: a wrong PIN answers only "4 attempts left"; the right PIN clocks the worker in through the
  kiosk-punch Edge Function (`supervisor-kiosk`).
- External crew (crew@example.com, engagement in Onboarding): no clock, no Crew tab, scanning and
  incidents closed with the "not active yet" refusal that names the next step (`crew-external-today`).

Findings filed: SIM-003 (voice note), SIM-004 (account deletion), SIM-005 (native Live Activity), SIM-006
(Field members see no asset unit) and SIM-007 (Field reads as supervisor). SIM-001 and SIM-002 are fixed.
