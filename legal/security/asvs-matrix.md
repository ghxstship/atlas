# OWASP ASVS 5.0 Level 2 Control Matrix

> **Draft for review by counsel before launch.** This matrix is a draft. It takes effect when the Owner approves it, and its effective date is that date of approval.

Section 9 of the build specification sets the OWASP Application Security Verification Standard 5.0 at Level 2 as the verification standard for XOS 4.0, and requires every control to map to a test or document here. This Wave 1 matrix lists each ASVS 5.0 chapter, the control areas within it as they apply to XOS (described in our own words), the owning agent, and the planned test or document. Every row is **Planned** with its wave.

In Wave 6, A22 (Security Review) expands each row to the individual Level 1 and Level 2 requirement identifiers of the published standard, records the test that proves each one, and marks it Verified, Not Applicable with a reason, or Failed with a linked finding. A22 never fixes its own findings; the owning agent does.
