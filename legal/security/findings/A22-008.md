# A22-008: Relational data in JSON and arrays in the workforce forms, surveys and quizzes

## Severity rationale

Low. This is not a security flaw, but gate 29 blocks release on any normal form violation missing
from the register. ADR 0002 allows JSON only for rich text documents, audit diffs and provider
payloads, and allows no arrays of repeating values. These columns are none of those.

## Location

- `supabase/migrations/0803_workforce_forms.sql:90` and `:192`: `app.form_templates.fields` and `app.form_template_versions.fields` (jsonb): "Field
  definitions: key, label, kind, required, choices, points and show_if". This is a table of fields,
  with a nested repeating group of choices, held in one JSON value.
- `0803_workforce_forms.sql:218`: `app.form_submissions.answers` (jsonb): "Answers keyed by field key". This is a table of
  answers that references fields by a key inside another row's JSON.
- `supabase/migrations/0801_workforce_feed_polls_surveys.sql:785`: `app.survey_questions.choices text[]`.
  `0801:842` `app.survey_answers.choice text` restates the chosen label with no reference.
- `supabase/migrations/0804_workforce_training_handbook.sql:157`: `app.training_quiz_questions.options text[]`.
  `0804:178` `app.training_quiz_keys.correct_option smallint` points at an array position (1 to 6).
  Reordering or editing the options silently changes which answer is correct.

## Reproduction

```sql
select a.attrelid::regclass, a.attname, format_type(a.atttypid, a.atttypmod), col_description(a.attrelid, a.attnum)
from pg_attribute a
where (a.attrelid, a.attname) in (
  ('app.form_templates'::regclass, 'fields'), ('app.form_template_versions'::regclass, 'fields'),
  ('app.form_submissions'::regclass, 'answers'), ('app.survey_questions'::regclass, 'choices'),
  ('app.training_quiz_questions'::regclass, 'options'));

-- The quiz key is a position in another row's array.
select pg_get_constraintdef(oid) from pg_constraint where conname = 'training_quiz_keys_option';
-- CHECK ((correct_option >= 1) AND (correct_option <= 6))
```

## Impact

- No foreign key protects an answer, a choice or a correct option, so edits to a question can make
  stored answers and quiz grading point at the wrong option.
- Reports cannot join answers to choices without parsing JSON, and the schema lint required by
  Section 3.15 (JSON holding relational data, arrays of repeating values) cannot pass.

## Suggested fix

Model the repeating groups as tables:

- `form_fields` and `form_field_choices`, with rows per template version;
- `form_answers`, one row per submission and field, referencing `form_fields`;
- `survey_question_choices`, with `survey_answers.survey_question_choice_id`;
- `training_quiz_options`, with `training_quiz_keys.correct_option_id`.

Keep `show_if` as a documented expression column if it must stay structured text, and record that
exception in ADR 0002.
