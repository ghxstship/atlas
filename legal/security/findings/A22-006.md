# A22-006: Stripe entity name in the subprocessor list

## Severity rationale

Low. No data is exposed, but the list names an entity that is not the party to the Stripe Services
Agreement for a United States account, so customers would record the wrong processor.

## Location

`legal/subprocessors.md:43` names "Stripe, Inc.".

## Reproduction

Read the Stripe Services Agreement, Section 12 (Definitions), at https://stripe.com/legal/ssa, as of
2026-10-16. The row for the United States names "Stripe, LLC", with "Stripe Payments Company" as an
additional party only where the applicable Financial Services Terms say so (for example, Connect
payouts).

## Impact

Customers' records of processing and the DPA's subprocessor notice would name the wrong Stripe
entity, for billing and for Stripe Connect payouts to External Parties.

## Suggested fix

Name "Stripe, LLC" in `legal/subprocessors.md`. Where Stripe Connect payouts are enabled, add
"Stripe Payments Company" for the payout services if the Connect terms make it a party. Leave the
final wording to counsel.
