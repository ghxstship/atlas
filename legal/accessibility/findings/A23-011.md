# A23-011: Atlas has no skip link

## Severity rationale

Moderate. Atlas pages expose landmarks (`navigation` regions and `main`), which is a sufficient
technique for 2.4.1 for screen reader users, so this is not a conformance failure for them. Sighted
keyboard users have no bypass, though: the first stop on every page is the org switcher, and main
content starts about 15 stops later (org switcher, Search, Workspace, Quick Access, Pin page,
Projects, five group toggles, Activity, Settings). Gateway already ships a skip link, and the copy
for Atlas exists (`shell.skipToContent`) but is never rendered.

## Location

- `apps/atlas/components/shell/shell-frame.tsx`: no skip link before the sidebar.
- `packages/i18n/messages/en-US/shell.json:813`: `skipToContent`, unused.
- Every Atlas session route: the sweep reports `focus: first stop is button "Demo Productions",
not a skip link` (registered in apps/atlas/e2e/a11y/known.ts).

## Reproduction

Open any Atlas page, for example `/demo-productions/home`, click the address bar and press Tab. Focus
goes to the org switcher, and no "Skip to content" link appears.

## Suggested fix

Render a visually hidden, focus-visible "Skip to content" link as the first element of the shell
(as `apps/gateway/components/shell/gateway-frame.tsx:197` does) pointing at `main` with
`id="content"` and `tabIndex={-1}`.
