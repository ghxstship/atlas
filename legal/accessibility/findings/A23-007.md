# A23-007: The clock button stops growing at 160 percent

## Severity rationale

Moderate. Section 14.1 requires Dynamic Type and font scaling to 200 percent. The `Text` primitive
honours that (`maxFontSizeMultiplier={2}`), but the clock button label and timer, the most used
control in Compass, stop at 1.6. Low-vision field staff at the largest sizes get a smaller label
on the one button they need most.

## Location

- `apps/compass/src/ui/compass.tsx:95` and `:103` (`ClockButton` label and timer):
  `maxFontSizeMultiplier={1.6}`.

## Reproduction

Set iOS Text Size to the largest accessibility size (or Android font scale 2.0), open Today. The
detail line grows to 200 percent; "Clock in" and the timer stop at 160 percent.

## Suggested fix

Use `maxFontSizeMultiplier={2}` on both, and let the button grow (it already uses `minHeight`), or
wrap the timer to a second line at large sizes.

## Resolution

- Fixed in: 684526f (A35).
- Verified by: apps/compass/test/a23-moderate.test.ts (A23-007 block): no Compass text caps its multiplier below 2.
