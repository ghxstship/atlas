# A23-016: The phone menu button has no tooltip

## Severity rationale

Moderate. Below the large breakpoint the shell shows an icon-only menu button. It has an accessible
name ("Open navigation") and `aria-expanded`, so assistive technology is fine, but it is a raw
`<button>` instead of `IconButton`, so it has no tooltip. Gate 31 requires one on every icon-only
control, and sighted people with cognitive disabilities rely on it. The sweep flags it on every
Atlas route at 375 px (530 times across roles).

## Location

- `packages/ui/src/Layout/Layout.tsx:114` (menu button, `aria-label={t("shell.menu")}`).

## Reproduction

Open any Atlas page at 375 px, hover or long press the menu button at the top left: no tooltip
appears, and the element has no `title` and no tooltip trigger.

## Suggested fix

Render it with `IconButton` (label `t("shell.menu")`), or wrap it in the design system `Tooltip`,
keeping the `ref`, `aria-expanded` and `aria-controls`.
