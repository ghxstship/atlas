# A23-005: The offline banner hides its View action from VoiceOver and TalkBack

## Severity rationale

Serious. The offline banner is the always-visible entry to the offline queue (Section 11.13: every
action works offline, with the queue visible). It wraps the whole banner in an `accessible` View,
which makes it a single element: VoiceOver and TalkBack read the message but cannot focus or
activate the View button inside it, so a screen reader user cannot reach the queue from the banner.
The wrapper also masks the inner `alert` role.

## Location

- `apps/compass/src/ui/layout.tsx:400` to `:403` (`OfflineBanner`): `<View accessible
accessibilityLabel=...>` around `Banner`, whose action button renders at `:352`.
- Used by `apps/compass/src/screens/common.tsx:141` on every screen.

## Reproduction

Source audit (confirm on device):

1. Go offline in Compass with one punch queued. The banner shows "Offline (1)" and a View button.
2. With VoiceOver, swipe through the banner. Only "Offline, 1 action waiting" is read; View is never
   focused, and double tapping the banner does nothing.

## Suggested fix

Drop the `accessible` wrapper. Put the combined label (message and queued count) on the message
Text, keep View as its own button, and announce count changes through the helper in A23-004.
