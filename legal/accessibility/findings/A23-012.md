# A23-012: The records list grid has no column headers

## Severity rationale

Moderate. The List view renders `role="grid"` with rows of `gridcell`s and no `columnheader` row,
visible or hidden. A screen reader moving across a row hears "Proposed, NWS-1, Load-In Window,
Timeline, Mar 10, 2027, 7:00 AM, Demo Producer" with nothing to say which value is the start date
or the owner. Each row's full text is its accessible name, which helps; cell-by-cell navigation does
not. The Table view (DataTable) is not affected.

## Location

- `packages/ui/src/Views/Views.tsx:169` (`role="grid"` list), used by every records list in its
  List view, for example `/demo-productions/work/all-records`.

## Reproduction

Open `/demo-productions/work/all-records` in List view and read the accessibility tree:
`grid "All Records records"` contains `row` and `gridcell` only; `getByRole("columnheader")` finds 0.

## Suggested fix

Add one `role="row"` of `role="columnheader"` cells (class `sr-only` if the design keeps the list
headless), or render the list as `role="list"` with `listitem`s whose cells carry visually hidden
labels ("Starts", "Owner").
