# ButtonLink

ButtonLink is a link drawn as a button, for calls to action that navigate.

Use it wherever a call to action goes to another page; Button stays for actions that happen in place. The `xl` size is 44 px tall and is the call to action size on public pages. Labels are at most three words and start with a verb. A page shows one primary ButtonLink per view; the rest are secondary or ghost.

The consumer provides `href` and the label. `external` opens a new tab with `rel="noopener noreferrer"`.
