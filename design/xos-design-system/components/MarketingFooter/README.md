# MarketingFooter

MarketingFooter closes a public page with link columns, the legal line, and the language and theme controls.

Link columns sit in two columns on phones and in one row from bp-sm; every link stays visible at every width. The language control lists only the locales of open territories, so a closed territory's language is never offered. The theme control switches Dark, Light and Sunlight.

The consumer provides a BrandMark, the columns, the legal line and the open locales.
