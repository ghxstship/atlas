# LogoSlotWall

LogoSlotWall shows customer marks, or the empty slots that reserve their place in a design.

With no `logos` and no `slots` it renders nothing, so a page ships without it until customers have consented to the use of their marks. `slots` draws BrandSlot placeholders at 160 by 40 for design review only. Marks render through BrandMark with a light and a dark file per theme.

The consumer provides each mark with its owner's written consent. Never draw or approximate a mark.
