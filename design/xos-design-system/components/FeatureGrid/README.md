# FeatureGrid

FeatureGrid arranges short feature cards in two to five columns.

An item with a department `code` draws that department's glyph and prints the code in a mono chip beside the name, so a code never appears alone; coded items stay in numeric order. Other items take any Lucide `icon`. Columns collapse to two from bp-sm and one below.

The consumer provides a title, one sentence of body copy and, where it helps, one link per item.
