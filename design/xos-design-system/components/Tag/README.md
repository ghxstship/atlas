# Tag

Tag labels a record with a short category; the dot carries tone and the text stays `text-secondary` for contrast.

A `swatch` (`cat-1` to `cat-7`) colors the dot with a themed categorical token instead of the tone, for categories people define themselves: a custom field choice or a show segment (ADR 0142). The label always shows beside the swatch, so color is never the only signal; in forced colors the dot takes the text color and the tag keeps its border.
