# Tag

Tag labels a record with a short category; the dot carries tone and the text stays `text-secondary` for contrast.

A `swatch` (`cat-1` to `cat-7`) colours the dot with a themed categorical token instead of the tone, for categories people define themselves: a custom field choice or a show segment (ADR 0142). The label always shows beside the swatch, so colour is never the only signal; in forced colors the dot takes the text colour and the tag keeps its border.
