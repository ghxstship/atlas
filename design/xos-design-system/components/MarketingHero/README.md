# MarketingHero

MarketingHero opens a public page with the display heading, a lead, at most two calls to action and a product image.

The default variant sets the heading in display-64 beside a ScreenshotFrame and stacks below bp-lg. The `compact` variant centers a display-48 heading with no media and closes a page. A page has one default hero, and it carries the only `h1`.

`note` holds terms that must sit beside the buttons, such as trial length and what happens when the trial ends. The consumer provides `title`, `lead`, ButtonLink elements as `actions`, and a ScreenshotFrame as `media`.
