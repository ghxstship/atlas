# SurfaceTriptych

SurfaceTriptych presents the three XOS surfaces side by side, each with its audience and its release status.

Each card names the surface, who uses it and what it does, and carries a Tag with the status. Status is always a word beside the dot, never color alone. A surface that is not released says so here; the page never implies availability the source does not support.

The consumer provides name, audience, body, status and up to three points per surface.
