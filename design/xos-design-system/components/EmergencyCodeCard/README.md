# EmergencyCodeCard

EmergencyCodeCard shows one emergency code's protocol for one operational domain, readable offline in Compass Reference.

- Emergency codes are global (decision D15). The 14 codes (Code Red through Code Adam) and their protocol per operational domain (Site, Stage, Food & Beverage, Guest Experience, Back of House, Front of House Operations) are one Standard Library shared by every organization and project. Record keys sort in numeric order (EMG-001 onward).
- Protocol steps never name an agency. They name a service as `{fire}`, `{ems}`, `{lawEnforcement}`, `{bombSquad}` or `{federal}`, and the card resolves each from `authorities`, the responding agencies for the project's jurisdiction. Matching agencies are listed under the steps with their contact. Without a jurisdiction, the generic service name renders ("local law enforcement"), so the card is always correct.
- The radio channel is a project join from Radio Channels, not part of the code.
- `swatch` names an `ecode-*` token. The swatch is for recognition only; the code name is always written out, so color never carries the meaning alone.
- The preview shows Standard Library rows EMG-001, EMG-007 and EMG-025 with the CSMIA26 venue jurisdiction (Mana Wynwood, US-FL-MIAMI-DADE in Bible tab 11). EMG-025 has no authorities passed and shows the generic service name.
- This card is text. Never draw or approximate a regulatory safety symbol (ISO 7010, ISA) here; licensed marks go in their own slot.
