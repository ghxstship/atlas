# BrandSlot

BrandSlot marks where a tenant uploads a brand file in White Label settings, with its size and formats.

- Slots: Logo Light, Logo Dark, Favicon, App Icon (Enterprise branded builds), Splash (Enterprise branded builds).
- Pass the delivery size as `width` and `height` in pixels. The frame is drawn in proportion, at most 160 by 148, and the caption states the delivery size.
