How to read these screens

The note beside each screen lists its interaction notes and keyboard shortcuts, responsive behavior, and accessibility notes: focus order, landmarks and announcements.

Every screen has a Theme tweak: Dark, Light or Sunlight. Atlas and Compass open in Dark; Gateway opens in Light, standing in for System.

Size sheets reuse the same screen files at another width, so the 1280, 1024, 430 and tablet views show the real responsive rules, not redrawn copies.
