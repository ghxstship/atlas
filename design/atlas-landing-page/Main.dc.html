Built for Every Role

One record for the office, the field and your partners.

Atlas gives each role its own view of the same production. Producers see gate readiness, finance sees commitments against purchase orders, coordinators see advancing and logistics, and field crew see the day. External parties work through Gateway at no cost.

One Lifecycle, Nine Gates

Every production moves through nine gates.

Atlas runs each production through nine gates in three acts: Plan, Build and Show. Each gate lists its criteria, and a blocking criterion without evidence stops the gate from opening. The database enforces that rule, so the state of a project is a record, not an opinion.

Three Surfaces, One Record

Your team, your partners and your crew on one record.

XOS serves three surfaces from one backend, one database and one API. Atlas is the workspace for your team, Gateway is the portal for the companies and people you engage, and Compass is the field app. A change made in one is the same record in the others.

One Workspace

Every department works in the same project.

Atlas organizes work under ten departments, from Executive to Technology, and groups its modules into Production, Operations, People, Commercial and Knowledge. Each discipline works in its own module, and every module reads and writes the same project.

Open by Design

Open source platform. Documented API. Your data stays yours.

Atlas is open source. The platform is licensed under AGPL-3.0, and the SDKs, command line tool, MCP server, design tokens and UI libraries are licensed under MIT. A public API is documented in OpenAPI 3.1, so your integrations build on a published contract.

Aurora AI

AI that stays off until an Admin turns it on.

Aurora is the set of AI features in Atlas. Every feature is off until an organization Admin turns it on, and each of the six features has its own switch. Aurora uses Anthropic Claude models. AI output can be wrong, so check it before you rely on it.

Six switches, each off by default

  • Assistant
  • Ask in Plain Language
  • Document Extraction
  • Drafting
  • Summaries
  • Mapping Help

Security, Privacy & Accessibility

Security, privacy and accessibility, documented in public.

Atlas publishes its Security Overview, Privacy Policy, Subprocessor List, Accessibility Statement and Service Level Agreement. SOC 2 Type II and ISO/IEC 27001 programs are in readiness, and Atlas holds no certification today. The accessibility target is WCAG 2.2 Level AA.

Pricing

Start free. Upgrade when the show grows.
